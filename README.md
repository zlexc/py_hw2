# Домашнее задание № 2: примитивная база данных

Консольное приложение на Python в процедурном стиле. Устанавливаемый пакет
называется `primitive_db`, команда запуска — `project`.

Требуются Python 3.12 и uv версии 0.5 или выше.

## Запуск

Выполняйте команды из директории `python/homework_02`:

```sh
uv sync
uv run python -m primitive_db.main
uv run project
```

Обе команды запуска открывают один и тот же цикл ввода:

```text
Первая попытка запустить проект!

***
<command> exit - выйти из программы
<command> help - справочная информация
Введите команду: help
<command> exit - выйти из программы
<command> help - справочная информация
Введите команду: exit
```

`help` повторяет справку, `exit` завершает программу. Неизвестная команда
вызывает подсказку; пустой ввод повторяет запрос. Ctrl+C и конец ввода также
завершают программу без traceback. При импорте модулей программа не запускается.

`uv` создает `.venv` в директории проекта и устанавливает зависимости из
`uv.lock`. Для ручной активации окружения: `source .venv/bin/activate`.

## Проверка качества и сборка

```sh
uv run ruff --version
uv run ruff check .
uv run ruff format --check .
uv build
uvx twine check dist/*
```

Сборка создает wheel и исходный архив в `dist/`. Twine проверяет метаданные
локально; публикация на PyPI не требуется.

## Установка собранного пакета

```sh
uv tool install dist/*.whl
project
```

Это устанавливает команду в отдельное окружение инструмента. Если каталог
исполняемых файлов отсутствует в `PATH`, выполните `uv tool update-shell`
и перезапустите терминал. После изменения кода соберите пакет заново и
переустановите инструмент: `uv tool install --force dist/*.whl`.
